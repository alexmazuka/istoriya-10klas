# Синхронізація й код доступу до акаунта

На відміну від суміжного проєкту zoshyt-4klas (де синхронізація опційна), тут код доступу
**обов'язковий з першого входу** — без нього застосунком узагалі не можна користуватись, ані
учню, ані батькам. Так реалізовано «один акаунт, різні рівні доступу»: код відкриває спільні
дані, а PIN кабінету батьків — саме батьківський рівень доступу поверх нього.

## Як це влаштовано

- Один Firestore-документ `h10families/{код}` містить увесь прогрес (JSON-рядок). Кожен
  пристрій із тим самим кодом підписаний на зміни (`onSnapshot`) і надсилає власні зміни з
  затримкою ~1,5 с.
- Той самий Firebase-проєкт, що й у zoshyt-4klas (`zoshyt-4klas`, Firestore, план Spark,
  безкоштовний) — просто окрема колекція (`h10families`), дані фізично не перетинаються.
  Конфігурація — `js/firebase-init.js` (публічні ідентифікатори, не секрет).
- Код — 10 символів `XXXXX-XXXXX` (без символів, які легко переплутати).

## Перший вхід

1. На БУДЬ-ЯКОМУ пристрої (зазвичай батьківському) відкрити сайт → з'явиться екран доступу →
   вкладка «Створити новий» → «Створити код». З'явиться код виду `AB3K7-9XQPZ` — його треба
   записати (сайт також покаже його ще раз одразу після створення, і завжди видно в кабінеті
   батьків → Налаштування).
2. На пристрої учня (і на кожному наступному пристрої батьків) відкрити сайт → на екрані
   доступу вибрати «Ввести код» → ввести той самий код → «Приєднатися».
3. Готово: прогрес і кабінет батьків тепер спільні на всіх підключених пристроях.

## Технічні деталі

- Правила безпеки — `firestore.rules` у цій папці (оригінал редагується у Firebase Console).
- План безкоштовний (Spark): 50 000 читань і 20 000 записів на день.
- Резервна копія прогресу (кабінет батьків → Звіт → Експорт/Імпорт JSON) працює незалежно від
  синхронізації — додаткова підстраховка.
