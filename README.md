# 📜 Уроки історії — 10 клас, I семестр 2026/2027

Інтерактивний курс для **самостійного домашнього опрацювання історії** учнем 10 класу за
Типовою освітньою програмою III ступеня (10–11 класи), рівень стандарту. Два предмети —
**Історія України** та **Всесвітня історія**, за програмою МОН (наказ № 698 від 03.08.2022).
З автоматичною перевіркою вправ, ШІ-асистентом «Кліо» і кабінетом батьків.

🔗 **Сайт:** https://alexmazuka.github.io/istoriya-10klas/

## Що всередині

| Предмет | год/тиж | уроків/рік | наповнено |
|---|---:|---:|---|
| 🇺🇦 Історія України | 1,5 | 52 | вересень–жовтень (12 уроків) |
| 🌐 Всесвітня історія | 1 | 35 | вересень–жовтень (8 уроків) |

Кожен урок: **теорія** (+ необов'язкові додаткові матеріали) → **практика** (вправи з
автоперевіркою) → **домашнє завдання** (з розгорнутою письмовою відповіддю для перевірки
батьками) → **підсумок**. Уроки одного предмета відкриваються **послідовно** — наступний
доступний лише після завершення попереднього.

## Контроль для батьків

- Кабінет батьків (`parent.html`, доступ за приватним PIN): прогрес по тижнях і предметах,
  кожна відповідь учня, письмові роботи з кнопками «Прийнято» / «Повернути з коментарем»,
  журнал подій (включно з тим, що учень запитував у Кліо), звіт за тиждень.
- **Код доступу обов'язковий з першого входу** — і учень, і батьки вводять той самий код на
  своїх пристроях, після чого прогрес і кабінет батьків спільні в реальному часі
  ([sync/README.md](sync/README.md)).

## Структура

```
index.html            головна: уроки на сьогодні, борги, прогрес
week.html?w=N         розклад тижня       subject.html?s=ukr    уроки предмета
lesson.html?id=…      урок                parent.html           кабінет батьків
achievements.html     нагороди            about.html            програма, календар, юридична довідка
data/calendar.json    календар року (I семестр — точний, II — орієнтовний)
data/subjects.json    предмети            data/plan/*.json      тематичні плани (весь рік)
data/plan.json        зібраний план (tools/build_plan.py)
data/lessons/<subj>/  уроки JSON (наповнено вересень–жовтень)   tools/validate.py   перевірка схеми
js/, css/             рушій без залежностей і збірки (спільна архітектура з zoshyt-4klas)
js/ai-help.js         ШІ-асистент «Кліо»  sync/ai-help.md       застереження про приватність
sync/firestore.rules  правила безпеки Firestore (довідково)
```

## Розробка

```bash
python3 -m http.server 8765          # локальний перегляд: http://localhost:8765
python3 tools/validate.py            # перевірити всі уроки
python3 tools/build_plan.py -v       # перезібрати data/plan.json, показати уроки без файлу
```

Схема уроку та правила написання — в [AUTHORING.md](AUTHORING.md). Прогрес зберігається в
`localStorage` браузера й синхронізується через код доступу (обов'язковий).
