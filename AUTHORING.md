# Як писати уроки (схема JSON)

Кожен урок — окремий файл `data/lessons/<subject>/<id>.json`, де `subject` — `ukr` (Історія
України) або `world` (Всесвітня історія), `id` береться з `data/plan.json` (наприклад
`ukr-w02-d1`). Файл — валідний JSON (UTF-8, без коментарів). Перевірка:
`python3 tools/validate.py data/lessons/ukr/ukr-w02-d1.json` (або без аргументів — усі файли).

Мова — українська. Звертання до учня — на «ти», без панібратства й без дитячого тону: учень —
10-класник, 15–16 років, навчається вдома самостійно, дорослий поруч не завжди, тому кожне
пояснення має бути самодостатнім і точним. Це **історичний** матеріал — дати, імена, причинно-
наслідкові зв'язки мають бути фактично коректними; де історики розходяться в оцінках, чесно
пиши «за різними оцінками» / «дискусійне питання», а не подавай спірне як однозначний факт.

## Каркас файлу

```json
{
  "id": "ukr-w02-d1",
  "subject": "ukr",
  "title": "Воєнні дії на території України в 1914–1915 рр.",
  "goal": "Проаналізувати перебіг бойових дій на українських землях у перший рік Першої світової війни та їхній вплив на цивільне населення.",
  "minutes": 40,
  "theory": [ ...блоки теорії... ],
  "exercises": [ ...5–8 вправ з автоматичною перевіркою... ],
  "homework": [ ...3–5 завдань, серед них 1 розгорнута письмова відповідь... ],
  "extra": [ ...0–4 додаткові матеріали (статті, відео)... ],
  "reflection": ["Що з цього уроку варто запам'ятати найперше?", "Яке джерело здалось тобі найпереконливішим і чому?"]
}
```

- `id`, `subject`, `title` мають збігатися з `data/plan.json` (title можна злегка скоротити, тема та сама).
- `minutes` — орієнтовний час на урок разом із практикою (30–45).

## Блоки теорії (`theory`)

Порядок довільний, 4–9 блоків. Текст підтримує `**жирний**`, `*курсив*`, перенос рядка `\n`.

| type | поля | призначення |
|---|---|---|
| `p` | `text` | абзац пояснення |
| `rule` | `title`, `text` | ключова теза / визначення в рамці |
| `example` | `title`?, `text` | розібраний приклад аналізу (напр. причина → наслідок) |
| `list` | `title`?, `items[]` | маркований список |
| `steps` | `title`?, `items[]` | нумерована послідовність подій/дій |
| `table` | `title`?, `head[]`, `rows[][]` | таблиця; зокрема **хронологія**: `head:["Дата","Подія"]` |
| `reading` | `title`, `author`?, `text`, `genre`? | **уривок історичного джерела** (документ, спогад, промова) або авторський текст; abзаци через `\n\n` |
| `tip` | `text` | практична порада (як працювати з джерелом, на що звернути увагу) |
| `image` | `emoji`, `caption` | символічна позначка з підписом (файлів зображень немає) |

Для `reading` як історичного джерела: `author` — хто автор/звідки документ (напр. «З промови
М. Грушевського, березень 1917 р.»), `genre` — тип джерела («мемуари», «офіційний документ»,
«газетна стаття»). Текст джерела або переказуй своїми словами, або бери справді суспільне
надбання (офіційні документи, застарілі переклади); не видавай вигадану цитату за дослівну,
якщо не певен точного формулювання — перефразуй і познач це («за змістом промови…»).

## Додаткові матеріали (`extra`)

Необов'язковий масив, 0–4 елементи, для тих, хто хоче зрозуміти тему глибше:

```json
"extra": [
  {"title": "Стаття у Вікіпедії: Перша світова війна", "url": "https://uk.wikipedia.org/wiki/Перша_світова_війна", "type": "article"},
  {"title": "Лекція про 1917 рік в Україні", "url": "https://www.youtube.com/...", "type": "video", "note": "~15 хв"}
]
```

`type` — `"article"` або `"video"`. Посилання мають вести на реальні, існуючі, доречні сторінки —
перевір, що URL відкривається, перш ніж додавати. Найнадійніше джерело — стаття Вікіпедії
українською на точну тему уроку (майже завжди існує й стабільна). Якщо не впевнений щодо
конкретного відео — краще не додавати, ніж дати непрацююче чи нерелевантне посилання.

## Вправи (`exercises`) і домашнє завдання (`homework`)

Схема вправ ідентична для обох предметів, типи ті самі, що в суміжному проєкті zoshyt-4klas:

| type | обов'язкові поля | перевірка |
|---|---|---|
| `choice` | `options[]` (3–5), `answer` (індекс від 0) | один правильний варіант |
| `multi` | `options[]`, `answer[]` (індекси) | кілька правильних |
| `truefalse` | `items[{text, answer:true/false}]` (3–6) | так / ні |
| `fill` | `text` з пропусками у фігурних дужках: `"У {1917} р. утворено Центральну Раду"`; варіанти через `\|` | вписати дату/термін/ім'я; регістр і пробіли не важливі |
| `number` | `answer` (число) | числова відповідь (дата, кількість) |
| `input` | `answer[]` (прийнятні варіанти рядком) | коротка текстова відповідь (термін, ім'я) |
| `match` | `pairs[[ліво, право]]` (3–6) | з'єднати пари (подія–дата, постать–роль, термін–визначення) |
| `order` | `items[]` у ПРАВИЛЬНОМУ хронологічному порядку (3–7) | учень розставляє події по порядку |
| `sort` | `groups{ "Назва групи": [елементи] }` (2–3 групи) | розкласти по групах (напр. причини/наслідки) |
| `text` | `sample` (зразок розгорнутої відповіді), `min`? (типово 150 для домашніх) | аргументована письмова відповідь — перевіряють батьки |
| `checklist` | `items[]` | самоперевірка практичного завдання (напр. складання хронологічної таблиці) |

Правила:
1. У `exercises` мінімум 5 вправ з автоматичною перевіркою (не `text`/`checklist`).
2. У `homework` 3–5 завдань; хоча б одне `text` — розгорнута аргументована відповідь
   (`min` зазвичай 120–200 символів для 10 класу, не 20 як у молодшій школі) з опорою на
   факти з теорії уроку, а не переказ на кшталт «просто напиши що завгодно».
3. **Кожну відповідь перевір фактично.** Дати, імена, назви документів — звір із теорією
   цього ж уроку і з загальновідомими фактами; не вигадуй точні цифри (кількість жертв,
   чисельність військ), яких не пам'ятаєш напевно, — або дай узагальнену/приблизну форму.
4. Варіанти у `choice`/`multi` — правдоподібні (реальні альтернативні дати/постаті/події),
   без явних заглушок і без гумористичних варіантів.
5. Питання типу «чому» / «яке значення» краще формулювати через `text` (аргументація), а не
   `choice` — історичні причиново-наслідкові зв'язки рідко зводяться до одного варіанту.
6. Не копіюй дослівно текст із чужих підручників чи конспектів у мережі. Пиши власними словами.
7. Довжина файлу — орієнтовно 5–11 КБ.
